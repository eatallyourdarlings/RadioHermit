# RadioHermit

Progress shots (prototypes) go at Screenshots/

Any visual exploration goes at Art/

Any Ink experiments go at Ink/

The Unity Project is contained in Unity/ and any files that go in here will try to be imported by the engine, so don't put things like huge PNGs that aren't ready to be used as Assets! 

## Contributing

Fetch and pull all changes from remote.

Make a branch with your name and make sure you're working on that branch.

Make a commit at least once an hour, talking in verbs like "added Character Concept PNGs".

When you need to catch up, merge changes from the main branch onto your branch.
